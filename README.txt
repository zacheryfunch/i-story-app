STORY TIME — standalone local app (saves real files on disk)
===============================================================

WHAT THIS IS
A single web page (index.html) that runs entirely on your computer.
No internet connection or account needed. The first time you use it,
you choose a folder on your computer — Story Time then saves every
recording and cover picture there as normal files, which you can see
in Finder/File Explorer, back up, or move like any other files.

IMPORTANT: BROWSER REQUIREMENT
Saving real files this way uses a feature only Chrome and Microsoft
Edge support (on a computer, not a phone/tablet browser). Please use
one of those two browsers. Safari and Firefox can't do this yet — if
you open it there, the app will tell you.

HOW TO RUN IT
1. Keep index.html wherever you like (Desktop, a folder, etc.).
2. Double-click it — it opens in Chrome or Edge.
3. The first time, click "Choose folder" and pick (or create) a
   folder to hold your stories — e.g. a new folder called
   "Daughter's Stories" in your Documents.
4. That's it. Bookmark the page or make a shortcut for next time.

ADDING STORIES (parent step)
1. Click the small "Parent tools" button in the bottom-right corner.
2. Fill in the book title, choose a cover photo (optional), and choose
   the audio recording file.
3. Click "Save story" — it's written to the folder right away and
   appears on the shelf.
4. Delete any story from the same panel (this also removes its files
   from the folder).

WHAT'S INSIDE THE FOLDER
Story Time creates one subfolder per story, containing:
  audio.<ext>   — your recording, untouched
  cover.jpg     — the cover picture (if you added one)
  meta.json     — the title and a few details
You can safely rename the top-level folder or move it to a backup
drive; just remember to reconnect it if you move it (see below).

RECONNECTING
For security, browsers ask you to reconnect the folder each time you
fully restart Chrome/Edge — that's normal, not a bug. You'll see a
"Reconnect folder" button; one click and you're back in. As long as
you keep using the same browser on the same computer, it remembers
which folder to reconnect to.

MULTIPLE DEVICES / BONUS TIP
If you'd like the same library on more than one computer, point Story
Time at a folder that's inside a synced service you already use (e.g.
a Dropbox or Google Drive desktop folder). The files themselves will
sync between your computers, and on each one you just "Choose folder"
and pick that same synced folder once.

BACKING UP
Since the files are normal audio/image files, your regular backup
routine (Time Machine, an external drive, cloud sync, etc.) will pick
them up automatically — no special export step needed.
